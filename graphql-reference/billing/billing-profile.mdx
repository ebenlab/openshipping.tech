---
title: "billingProfile"
description: "Retrieve the billing profile"
---

`query` · Module: **Billing**

## Arguments

None.

## Returns

`BillingProfile!`

| Field | Type |
|---|---|
| `object` | `BillingProfileObject!` |
| `account` | `String!` |
| `currency` | `String` |
| `cycle` | `BillingProfileCycle` |
| `plans` | `[String!]` |
| `payment_methods` | `BillingProfilePaymentMethods` |
| `collection` | `BillingProfileCollection` |
| `balance` | `BillingProfileBalance` |
| `invoice_delivery` | `BillingProfileInvoiceDelivery` |
| `tax` | `BillingProfileTax` |
| `payments_connection` | `String` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
