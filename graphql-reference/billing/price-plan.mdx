---
title: "pricePlan"
description: "Retrieve a PricePlan"
---

`query` · Module: **Billing** · Requires `billing:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`PricePlan!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `PricePlanObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `name` | `String!` |
| `currency` | `String!` |
| `base_fee` | `PricePlanBaseFee` |
| `prices` | `[PricePlanPricesItem!]!` |
| `minimum` | `PricePlanMinimum` |
| `status` | `PricePlanStatus` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
