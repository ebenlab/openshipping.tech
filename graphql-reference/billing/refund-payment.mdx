---
title: "refundPayment"
description: "Refund a payment"
---

`mutation` · Module: **Billing** · Requires `billing:write` · `Idempotency-Key` header required

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |
| `input` | `RefundPaymentInput` | The fields for this operation. |

### `RefundPaymentInput` fields

| Field | Type |
|---|---|
| `amount` | `MoneyInput` |

`Refund!`

| Field | Type |
|---|---|

| `object` | `RefundObject!` |

| `payment` | `String!` |
