---
title: "reconciliation"
description: "Retrieve a Reconciliation"
---

`query` · Module: **Billing** · Requires `billing:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Reconciliation!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `ReconciliationObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `type` | `ReconciliationType!` |
| `invoice` | `String!` |
| `rules` | `String` |
| `status` | `ReconciliationStatus!` |
| `summary` | `JSON` |
| `lines` | `[ReconciliationLine!]` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
