---
title: "balance"
description: "Retrieve the prepaid balance"
---

`query` · Module: **Billing**

## Arguments

None.

## Returns

`Balance!`

| Field | Type |
|---|---|
| `object` | `BalanceObject` |
| `account` | `String` |
| `available` | `Money` |
| `pending` | `Money` |
| `low_balance_threshold` | `Money` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
