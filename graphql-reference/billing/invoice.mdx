---
title: "invoice"
description: "Retrieve a Invoice"
---

`query` · Module: **Billing** · Requires `billing:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Invoice!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `InvoiceObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `kind` | `InvoiceKind!` |
| `direction` | `InvoiceDirection` |
| `status` | `InvoiceStatus!` |
| `issuer` | `InvoiceIssuer` |
| `recipient` | `InvoiceRecipient` |
| `number` | `String` |
| `issued_on` | `String` |
| `due_on` | `String` |
| `period` | `InvoicePeriod` |
| `currency` | `String!` |
| `lines` | `[InvoiceLine!]!` |
| `totals` | `InvoiceTotals!` |
| `reconciliation` | `InvoiceReconciliation` |
| `source` | `InvoiceSource` |
| `documents` | `[Document!]` |
| `payments` | `[String!]` |
| `external_ids` | `[InvoiceExternalIdsItem!]` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
