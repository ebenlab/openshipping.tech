---
title: "payment"
description: "Retrieve a Payment"
---

`query` · Module: **Billing** · Requires `billing:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Payment!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `PaymentObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `amount` | `Money!` |
| `status` | `PaymentStatus!` |
| `invoice` | `String` |
| `purpose` | `PaymentPurpose` |
| `payment_method` | `String!` |
| `connection` | `String` |
| `failure` | `PaymentFailure` |
| `refunded` | `Money` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
