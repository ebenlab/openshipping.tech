---
title: "balanceTransactions"
description: "List balance transactions"
---

`query` · Module: **Billing**

## Arguments

| Argument | Type | Description |
|---|---|---|
| `type` | `String` | Filter by type. |
| `limit` | `Int` | Page size, 1–100 (default 10). |
| `startingAfter` | `ID` | Cursor: return objects after this ID. |
| `endingBefore` | `ID` | Cursor: return objects before this ID. |

## Returns

`BalanceTransactionList!`

| Field | Type |
|---|---|
| `data` | `[BalanceTransaction!]!` |
| `has_more` | `Boolean` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
