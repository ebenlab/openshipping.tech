`mutation` · Module: **Billing**

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

| `input` | `ResolveReconciliationInput` | The fields for this operation. |

| Field | Type |
|---|---|

`ReconciliationLine!`

| Field | Type |

| `shipment` | `String` |
