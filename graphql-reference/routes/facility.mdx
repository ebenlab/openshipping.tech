---
title: "facility"
description: "Retrieve a Facility"
---

`query` · Module: **Routes** · Requires `routes:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Facility!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `FacilityObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `name` | `String!` |
| `type` | `FacilityType!` |
| `status` | `FacilityStatus` |
| `contact` | `Contact!` |
| `location` | `FacilityLocation` |
| `timezone` | `String!` |
| `operating_hours` | `Recurrence` |
| `codes` | `JSON` |
| `capabilities` | `[String!]` |
| `service_zones` | `[String!]` |
| `functions` | `FacilityFunctions` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
