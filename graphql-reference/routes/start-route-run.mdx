---
title: "startRouteRun"
description: "Start a route run"
---

`mutation` · Module: **Routes** · Requires `routes:write`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`RouteRun!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `RouteRunObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `route` | `String` |
| `date` | `String!` |
| `status` | `RouteRunStatus!` |
| `scheduled_start` | `String` |
| `started_at` | `Int` |
| `completed_at` | `Int` |
| `vehicle` | `Vehicle` |
| `driver` | `Driver` |
| `stops` | `[RouteRunStopsItem!]!` |
| `legs` | `[RouteRunLegsItem!]` |
| `shipment_count` | `Int` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
