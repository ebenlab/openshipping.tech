`query` · Module: **Carriers**

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Carrier!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `CarrierObject!` |
| `name` | `String!` |
| `logo_url` | `String` |
| `status` | `CarrierStatus` |
| `countries` | `CarrierCountries` |
| `capabilities` | `[String!]!` |
| `services` | `[CarrierServicesItem!]` |
| `packagings` | `[CarrierPackagingsItem!]` |
| `label` | `CarrierLabel` |
| `standardized_features` | `[String!]` |
| `shipment_config_schema` | `JsonSchema` |
| `manifest_config_schema` | `JsonSchema` |
| `manifest` | `CarrierManifest` |
| `carrier_metadata_schema` | `JsonSchema` |
| `pickup_config_schema` | `JsonSchema` |
| `pickup` | `CarrierPickup` |
| `tracking` | `CarrierTracking` |
| `connection_methods` | `[ConnectionMethod!]` |
| `inbound` | `CarrierInbound` |
| `test_environment` | `CarrierTestEnvironment` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
