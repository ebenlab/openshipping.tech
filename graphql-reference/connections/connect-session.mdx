---
title: "connectSession"
description: "Retrieve a connect session"
---

`query` · Module: **Connections** · Requires `connections:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`ConnectSession!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `ConnectSessionObject!` |
| `livemode` | `Boolean` |
| `created` | `Int` |
| `status` | `ConnectSessionStatus!` |
| `mode` | `ConnectSessionMode` |
| `carrier` | `String!` |
| `app` | `String` |
| `url` | `String!` |
| `user_code` | `String` |
| `expires_at` | `Int!` |
| `return_url` | `String` |
| `connection` | `String` |
| `error` | `ConnectSessionError` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
