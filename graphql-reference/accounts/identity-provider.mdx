---
title: "identityProvider"
description: "Retrieve a IdentityProvider"
---

`query` · Module: **Accounts** · Requires `accounts:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`IdentityProvider!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `IdentityProviderObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `account` | `String!` |
| `type` | `IdentityProviderType!` |
| `status` | `IdentityProviderStatus` |
| `issuer` | `String!` |
| `client_id` | `String` |
| `client_secret` | `String` |
| `scopes` | `[String!]` |
| `domains` | `[IdentityProviderDomainsItem!]` |
| `claims` | `IdentityProviderClaims` |
| `role_mapping` | `[IdentityProviderRoleMappingItem!]` |
| `default_role` | `String` |
| `provisioning` | `IdentityProviderProvisioning` |
| `enforce` | `Boolean` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
