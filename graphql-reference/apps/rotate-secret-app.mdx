---
title: "rotateSecretApp"
description: "Rotate a dynamic app's client secret"
---

`mutation` · Module: **Apps** · Requires `connections:write`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |
