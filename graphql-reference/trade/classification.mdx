---
title: "classification"
description: "Retrieve a Classification"
---

`query` · Module: **Trade** · Requires `trade:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Classification!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `ClassificationObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `status` | `ClassificationStatus!` |
| `items` | `[ClassificationItemsItem!]!` |
| `messages` | `[Message!]` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).

<RequestExample>

```graphql Request
query Classification($id: ID!) {
  classification(id: $id) {
    id
    object
    status
    livemode
    created
    updated
    items {
      index
      sku
      export {
        country
        hs_code
        description
        confidence
      }
      import {
        country
        hs_code
        description
        confidence
      }
      requires_review
      rationale
    }
    messages {
      code
      level
      message
      param
      carrier
    }
  }
}
```

```json Variables
{
  "id": "cls_1a2B3c"
}
```
