---
title: "tariff"
description: "Look up a tariff line"
---

`query` · Module: **Trade**

## Arguments

| Argument | Type | Description |
|---|---|---|
| `country` | `ID!` | The country. |
| `hsCode` | `ID!` | The hs code. |
| `originCountry` | `String` | Filter by origin country. |
| `date` | `String` | Filter by date. |

## Returns

`Tariff!`

| Field | Type |
|---|---|
| `object` | `TariffObject` |
| `country` | `String` |
| `hs_code` | `String` |
| `description` | `String` |
| `duty` | `[TariffDutyItem!]` |
| `taxes` | `[TariffTaxesItem!]` |
| `restrictions` | `[TariffRestrictionsItem!]` |
| `valid_on` | `String` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
