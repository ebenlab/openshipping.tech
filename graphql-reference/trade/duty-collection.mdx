`query` · Module: **Trade** · Requires `trade:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`DutyCollection!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `DutyCollectionObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `status` | `DutyCollectionStatus!` |
| `shipment` | `String!` |
| `landed_cost` | `String` |
| `assessed` | `DutyCollectionAssessed` |
| `total` | `Money` |
| `variance` | `Money` |
| `assessed_at` | `Int` |
| `due_by` | `String` |
| `entry_number` | `String` |
| `payment` | `JSON` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
