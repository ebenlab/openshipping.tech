## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`ComplianceScreening!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `ComplianceScreeningObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `decision` | `ComplianceScreeningDecision!` |
| `parties` | `[ComplianceScreeningPartiesItem!]` |
| `items` | `[ComplianceScreeningItemsItem!]` |
| `embargo` | `ComplianceScreeningEmbargo` |
| `lists_version` | `String` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
