`query` · Module: **Integrations**

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`AddressValidation!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `AddressValidationObject!` |
| `status` | `AddressValidationStatus!` |
| `deliverability` | `AddressValidationDeliverability` |
| `input` | `Address` |
| `suggested` | `Address` |
| `alternatives` | `[Address!]` |
| `components` | `JSON` |
| `residential` | `Boolean` |
| `geocode` | `AddressValidationGeocode` |
| `changes` | `[String!]` |
| `connection` | `String` |
| `messages` | `[Message!]` |
| `carrier_metadata` | `CarrierMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
