`query` · Module: **Integrations** · Requires `integrations:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Coverage!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `CoverageObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `status` | `CoverageStatus!` |
| `shipment` | `String!` |
| `connection` | `String` |
| `policy_number` | `String` |
| `insured_value` | `Money!` |
| `premium` | `Money` |
| `coverage_types` | `[String!]` |
| `period` | `CoveragePeriod` |
| `certificate` | `String` |
| `claims` | `[String!]` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
