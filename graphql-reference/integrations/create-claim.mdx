`mutation` · Module: **Integrations** · Requires `integrations:write`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `input` | `ClaimInput` | The fields for this operation. |

| Field | Type |

| `type` | `String` |
| `amount` | `MoneyInput` |
