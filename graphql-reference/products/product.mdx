---
title: "product"
description: "Retrieve a Product"
---

`query` · Module: **Products** · Requires `products:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Product!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `ProductObject!` |
| `livemode` | `Boolean!` |

| `updated` | `Int` |
| `status` | `ProductStatus!` |
| `sku` | `String!` |
| `title` | `String` |
| `description` | `String` |
| `variant_of` | `String` |
| `options` | `JSON` |
| `category` | `String` |
| `brand` | `String` |
| `material` | `String` |
| `origin_country` | `String` |
| `manufacturer` | `ProductManufacturer` |
| `unit_value` | `Money` |
| `unit_net_weight` | `Weight` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).

    }
  }
}
