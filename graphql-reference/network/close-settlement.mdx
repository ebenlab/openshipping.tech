title: "closeSettlement"
description: "Close a settlement"
---

`mutation` · Module: **Network** · Requires `network:write`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Settlement!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `SettlementObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `account` | `String!` |
| `period` | `SettlementPeriod!` |
| `currency` | `String` |
| `totals` | `SettlementTotals` |
| `status` | `SettlementStatus!` |
| `statement` | `String` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
