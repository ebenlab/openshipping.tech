---
title: "networkMembers"
description: "List a carrier member"
---

`mutation` · Module: **Network** · Requires `accounts:write`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Account!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `AccountObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `type` | `AccountType!` |
| `carrier` | `AccountCarrier` |
| `status` | `AccountStatus!` |
| `parent` | `String` |
| `profile` | `AccountProfile` |
| `settings` | `AccountSettings` |
| `modules` | `[String!]` |
| `requirements` | `AccountRequirements` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
