---
title: "ledgerEntry"
description: "Retrieve a LedgerEntry"
---

`query` · Module: **Network** · Requires `network:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`LedgerEntry!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `LedgerEntryObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `type` | `LedgerEntryType!` |
| `shipment` | `String` |
| `parent_shipment` | `String` |
| `debit_account` | `String!` |
| `credit_account` | `String!` |
| `amount` | `Money!` |
| `basis` | `JSON` |
| `status` | `LedgerEntryStatus!` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
