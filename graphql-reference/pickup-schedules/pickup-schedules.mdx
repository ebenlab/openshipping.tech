title: "pickupSchedules"
description: "List pickup schedules"
---

`query` · Module: **Pickup Schedules** · Requires `pickups:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `status` | `String` | Filter by status. |
| `connection` | `String` | Filter by connection. |
| `carrier` | `String` | Filter by carrier. |
| `management` | `String` | Filter by management. |
| `createdGte` | `Int` | Filter by created gte. |
| `createdLte` | `Int` | Filter by created lte. |
| `limit` | `Int` | Page size, 1–100 (default 10). |
| `startingAfter` | `ID` | Cursor: return objects after this ID. |
| `endingBefore` | `ID` | Cursor: return objects before this ID. |

## Returns

`PickupScheduleList!`

| Field | Type |
|---|---|
| `data` | `[PickupSchedule!]!` |
| `has_more` | `Boolean` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
