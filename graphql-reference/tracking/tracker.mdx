---
title: "tracker"
description: "Retrieve a Tracker"
---

`query` · Module: **Tracking** · Requires `trackers:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Tracker!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `TrackerObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `tracking_number` | `String!` |
| `carrier` | `String!` |
| `connection` | `String` |
| `shipment` | `Shipment` |
| `status` | `TrackingStatusEnum!` |
| `status_detail` | `String` |
| `status_updated_at` | `Int` |
| `delivered_at` | `Int` |
| `estimated_delivery` | `TrackerEstimatedDelivery` |
| `origin` | `Location` |
| `destination` | `Location` |
| `signed_by` | `String` |
| `proof_of_delivery` | `ProofOfDelivery` |
| `attempts` | `Int` |
| `events` | `[TrackingEvent!]` |
| `tracking_url` | `String` |
| `public_url` | `String` |
| `refresh` | `TrackerRefresh` |
| `messages` | `[Message!]` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
