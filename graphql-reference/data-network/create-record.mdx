---
title: "createRecord"
description: "Write a record"
---

`mutation` · Module: **Data Network** · Requires `data:write`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `input` | `RecordCreate` | The fields for this operation. |

### `RecordCreate` fields

| Field | Type |
|---|---|
| `subject` | `RecordCreateSubjectInput` |
| `role` | `String` |

## Returns

`Record!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `RecordObject!` |
| `cid` | `String!` |
| `subject` | `RecordSubject!` |
| `previous` | `String` |
| `producer` | `String!` |
| `role` | `String` |
| `produced_at` | `String` |
| `schema` | `String` |
| `payload` | `RecordPayload` |
| `public_fields` | `JSON` |
| `signature` | `RecordSignature!` |
| `anchor` | `RecordAnchor` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
