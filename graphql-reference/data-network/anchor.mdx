---
title: "anchor"
description: "Retrieve an anchor"
---

`query` · Module: **Data Network**

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Anchor!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `AnchorObject!` |
| `ledger` | `AnchorLedger` |
| `merkle_root` | `String!` |
| `records` | `Int` |
| `created` | `Int` |
| `status` | `AnchorStatus!` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).

```graphql Request
query Anchor($id: ID!) {
  anchor(id: $id) {
    id
    object
    status
    ledger {
      network
      contract
      tx
      block
    }
    merkle_root
    records
    created
  }
}
```
