---
title: "timeline"
description: "End-to-end timeline"
---

`query` · Module: **Data Network** · Requires `data:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `shipmentId` | `ID!` | The shipment id. |

## Returns

`Timeline!`

| Field | Type |
|---|---|
| `object` | `TimelineObject!` |
| `shipment` | `String!` |
| `identifiers` | `[TimelineIdentifiersItem!]` |
| `milestones` | `[TimelineMilestonesItem!]!` |
| `events` | `TimelineEvents` |
| `gaps` | `[TimelineGapsItem!]` |
| `eta` | `TimelineEta` |
| `as_of` | `Int` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
