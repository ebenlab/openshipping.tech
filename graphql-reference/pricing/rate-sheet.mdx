title: "rateSheet"
description: "Retrieve a RateSheet"

`query` · Module: **Pricing** · Requires `pricing:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`RateSheet!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `RateSheetObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `name` | `String!` |
| `status` | `RateSheetStatus!` |
| `version` | `Int` |
| `currency` | `String!` |
| `effective_from` | `String` |
| `effective_until` | `String` |
| `services` | `[String!]` |
| `origin_zones` | `[String!]` |
| `weight_rounding` | `RateSheetWeightRounding` |
| `dimensional_weight` | `RateSheetDimensionalWeight` |
| `aggregate` | `RateSheetAggregate` |
| `rates` | `[RateSheetRatesItem!]!` |
| `surcharges` | `[String!]` |
| `assignments` | `RateSheetAssignments` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
