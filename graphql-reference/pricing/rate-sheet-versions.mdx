`query` · Module: **Pricing**

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`RateSheetList!`

| Field | Type |
|---|---|
| `data` | `[RateSheet!]!` |
| `has_more` | `Boolean` |
