---
title: "vehicle"
description: "Retrieve a Vehicle"
---

`query` · Module: **Fleet** · Requires `fleet:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Vehicle!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `VehicleObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `name` | `String!` |
| `type` | `VehicleType!` |
| `class` | `JSON` |
| `status` | `VehicleStatus!` |
| `registration` | `VehicleRegistration` |
| `capacity` | `VehicleCapacity` |
| `features` | `[String!]` |
| `home_facility` | `String` |
| `range` | `VehicleRange` |
| `telematics` | `VehicleTelematics` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
