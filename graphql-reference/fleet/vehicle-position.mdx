---
title: "vehiclePosition"
description: "Latest vehicle position"
---

`query` · Module: **Fleet**

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Position!`

| Field | Type |
|---|---|
| `at` | `String!` |
| `latitude` | `Float!` |
| `longitude` | `Float!` |
| `heading` | `Float` |
| `speed` | `PositionSpeed` |
| `accuracy_m` | `Float` |
| `source` | `PositionSource` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
