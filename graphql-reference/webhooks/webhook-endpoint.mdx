---
title: "webhookEndpoint"
description: "Retrieve a WebhookEndpoint"
---

`query` · Module: **Webhooks** · Requires `webhooks:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`WebhookEndpoint!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `WebhookEndpointObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `url` | `String!` |
| `description` | `String` |
| `enabled_events` | `[String!]!` |
| `status` | `WebhookEndpointStatus!` |
| `api_version` | `String` |
| `filters` | `WebhookEndpointFilters` |
| `secret` | `String` |
| `secret_preview` | `String` |
| `disabled_reason` | `String` |
| `delivery` | `WebhookEndpointDelivery` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
