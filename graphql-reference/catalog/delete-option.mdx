---
title: "deleteOption"
description: "Delete a draft option"
---

`mutation` · Module: **Catalog** · Requires `catalog:write`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`DeletedObject!`

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).

<RequestExample>

```graphql Request
mutation DeleteOption($id: ID!) {
  deleteOption(id: $id)
}
```

```json Variables

  "id": "obj_1a2B3c"
}
```

</RequestExample>
