---
title: "publishPackaging"
description: "Publish a packaging"
---

`mutation` · Module: **Catalog** · Requires `catalog:write`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |
| `input` | `PublishPackagingInput` | The fields for this operation. |

### `PublishPackagingInput` fields

| Field | Type |
|---|---|
| `effective_from` | `String` |

| `outer_dimensions` | `Dimensions` |
