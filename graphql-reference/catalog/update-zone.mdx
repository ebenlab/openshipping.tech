`mutation` · Module: **Catalog** · Requires `catalog:write`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |
| `input` | `ZoneInput` | The fields for this operation. |

| Field | Type |
|---|---|
| `name` | `String` |
| `purpose` | `[ZoneInputPurposeItem!]` |
| `area` | `AreaInput` |
| `priority` | `Int` |
| `status` | `ZoneInputStatus` |
| `version` | `Int` |
| `user_metadata` | `UserMetadataInput` |
