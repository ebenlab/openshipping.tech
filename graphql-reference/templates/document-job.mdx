---
title: "documentJob"
description: "Retrieve a DocumentJob"
---

`query` · Module: **Templates** · Requires `templates:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`DocumentJob!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `DocumentJobObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `template` | `String` |
| `type` | `String` |
| `status` | `DocumentJobStatus!` |
| `counts` | `DocumentJobCounts` |
| `output` | `DocumentJobOutput!` |
| `result_file` | `String` |
| `errors` | `[DocumentJobErrorsItem!]` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).

<RequestExample>

```graphql Request
query DocumentJob($id: ID!) {
  documentJob(id: $id) {
    id
    object
    type
    status
    livemode
    created
    updated
    template
    counts {
      total
      succeeded
      failed
    }
    output
    result_file
    errors {
      object
      code
      message
    }
  }
}
```

```json Variables
}
```
