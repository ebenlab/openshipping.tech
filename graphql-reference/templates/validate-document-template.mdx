---
title: "validateDocumentTemplate"
description: "Validate a template"
---

`mutation` · Module: **Templates** · Requires `templates:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`ValidateDocumentTemplateResult!`

| Field | Type |
|---|---|
| `valid` | `Boolean` |
| `errors` | `[ValidateDocumentTemplateResultErrorsItem!]` |
| `unknown_fields` | `[String!]` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
