---
title: "documentIngestion"
description: "Retrieve a DocumentIngestion"
---

`query` · Module: **Templates** · Requires `templates:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`DocumentIngestion!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `DocumentIngestionObject!` |
| `status` | `DocumentIngestionStatus!` |
| `type` | `String` |
| `detected_type` | `String` |
| `format` | `DocumentIngestionFormat` |
| `file` | `String!` |
| `extraction` | `DocumentIngestionExtraction` |
| `attach_to` | `DocumentIngestionAttachTo` |
| `document` | `String` |
| `job` | `String` |
| `messages` | `[Message!]` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
