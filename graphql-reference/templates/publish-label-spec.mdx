title: "publishLabelSpec"
description: "Publish a label spec"

`mutation` · Module: **Templates** · Requires `templates:write`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

`LabelSpec!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `LabelSpecObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `owner` | `String` |
| `carrier` | `String!` |
| `template` | `String!` |
| `services` | `[String!]` |
| `sizes` | `[String!]` |
| `dpi` | `[Int!]` |
| `required_fields` | `[String!]` |
| `barcodes` | `[LabelSpecBarcodesItem!]` |
| `zones` | `[LabelSpecZonesItem!]` |
| `tracking_numbers` | `LabelSpecTrackingNumbers` |

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
