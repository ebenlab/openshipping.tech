---
title: "documentTemplate"
description: "Retrieve a DocumentTemplate"
---

`query` · Module: **Templates** · Requires `templates:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`DocumentTemplate!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `DocumentTemplateObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `name` | `String!` |
| `slug` | `String` |
| `type` | `String!` |
| `status` | `DocumentTemplateStatus!` |
| `version` | `Int` |
| `related_object` | `DocumentTemplateRelatedObject!` |
| `engine` | `DocumentTemplateEngine!` |
| `source` | `String!` |
| `assets` | `JSON` |
| `page` | `DocumentTemplatePage` |
| `formats` | `[DocumentTemplateFormatsItem!]` |
| `locale` | `String` |
| `triggers` | `[DocumentTemplateTriggersItem!]` |
| `attach_to` | `DocumentTemplateAttachTo` |
| `default_for` | `[String!]` |
| `preview` | `DocumentTemplatePreview` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
