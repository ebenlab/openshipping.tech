---
title: "inboundEvent"
description: "Retrieve a InboundEvent"
---

`query` · Module: **Inbound** · Requires `inbound:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`InboundEvent!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `InboundEventObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `type` | `InboundEventType!` |
| `source` | `InboundEventSource` |
| `status` | `InboundEventStatus!` |
| `connection` | `String` |
| `tracker` | `String` |
| `shipment` | `String` |
| `accepted` | `Int` |
| `rejected` | `Int` |
| `errors` | `[InboundEventErrorsItem!]` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
