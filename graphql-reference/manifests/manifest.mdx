---
title: "manifest"
description: "Retrieve a Manifest"
---

`query` · Module: **Manifests** · Requires `manifests:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Manifest!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `ManifestObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `status` | `ManifestStatus!` |
| `mode` | `ManifestMode!` |
| `trigger` | `ManifestTrigger!` |
| `connection` | `String!` |
| `carrier` | `String` |
| `ship_date` | `String` |
| `timezone` | `String` |
| `address` | `Address` |
| `group` | `String` |
| `shipments` | `[String!]` |
| `shipment_count` | `Int` |
| `handling_unit_count` | `Int` |
| `total_weight` | `Weight` |
| `carrier_manifests` | `[ManifestCarrierManifestsItem!]` |
| `documents` | `[Document!]` |
| `pickup` | `Pickup` |
| `errors` | `[ManifestErrorsItem!]` |
| `reference` | `String` |
| `submitted_at` | `Int` |
| `messages` | `[Message!]` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
