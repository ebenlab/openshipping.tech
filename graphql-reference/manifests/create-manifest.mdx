---
title: "createManifest"
description: "Create (close out) one or more manifests"
---

`mutation` · Module: **Manifests** · Requires `manifests:write` · `Idempotency-Key` header required

Returns a `list` when `split: auto` produced several manifests (one per carrier scope).
