---
title: "rateQuote"
description: "Retrieve a rate quote"
---

`query` · Module: **Rates** · Requires `rates:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`RateQuote!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `RateQuoteObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `expires_at` | `Int!` |
| `shipment` | `String` |
| `request` | `RateQuoteRequest` |
| `rates` | `[Rate!]!` |
| `errors` | `[ConnectionError!]!` |
| `messages` | `[Message!]` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
