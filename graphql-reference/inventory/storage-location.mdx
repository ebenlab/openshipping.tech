`query` · Module: **Inventory** · Requires `inventory:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`StorageLocation!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `StorageLocationObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `facility` | `String!` |
| `code` | `String!` |
| `path` | `StorageLocationPath` |
| `type` | `StorageLocationType!` |
| `temperature_class` | `StorageLocationTemperatureClass` |
| `capacity` | `StorageLocationCapacity` |
| `restrictions` | `StorageLocationRestrictions` |
| `status` | `StorageLocationStatus` |
| `barcode` | `String` |
| `pick_sequence` | `Int` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
