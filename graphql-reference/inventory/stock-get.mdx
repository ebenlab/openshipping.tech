---
title: "stockGet"
description: "Retrieve a Stock"
---

`query` · Module: **Inventory** · Requires `inventory:read`

## Arguments

| Argument | Type | Description |
|---|---|---|
| `id` | `ID!` | The object's ID. |

## Returns

`Stock!`

| Field | Type |
|---|---|
| `id` | `String!` |
| `object` | `StockObject!` |
| `livemode` | `Boolean!` |
| `created` | `Int!` |
| `updated` | `Int` |
| `owner` | `String!` |
| `product` | `String!` |
| `facility` | `String!` |
| `location` | `String` |
| `status` | `StockStatus!` |
| `quantity` | `Int!` |
| `lot` | `StockLot` |
| `serials` | `[String!]` |
| `handling_unit` | `String` |
| `user_metadata` | `UserMetadata` |
| `carrier_metadata` | `CarrierMetadata` |
| `system_metadata` | `SystemMetadata` |

## Errors

Errors are returned in `errors[]`, with the REST error object in `extensions` (`type`, `code`, `param`, `request_id`), using the codes in [Conventions §9](/spec/00-conventions).
