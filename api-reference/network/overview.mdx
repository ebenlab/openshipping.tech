**Network mode** is for carrier and LSP networks, marketplaces and alliances whose members serve first, middle or last mile. This reference lists only the operations a Network implementation exposes, following the mode profile in [Modes §2](/spec/12-modes). Switch modes from the **REST Interface** tab menu at the top of the page.

| `core` | Required | Rates, Shipments, Tracking, Events, Carriers, Batches, Test Helpers, Discovery | 32 |
| `webhooks` | Required | Webhooks, Inbound | 11 |
| `pickups` | Required | Pickups, Pickup Schedules | 17 |
| `manifests` | Optional | Manifests | 6 |
| `documents` | Optional | Files, Document Uploads | 9 |
| `connections` | Optional | Connections | 9 |
| `platform` | Required | Accounts | 5 |

Required modules are grouped first in the sidebar, optional ones after. Every module is part of this mode.

The machine-readable file for this mode is [`/openapi/network.yaml`](/openapi/network.yaml). The complete document, with every module, is [`/openapi.yaml`](/openapi.yaml).
